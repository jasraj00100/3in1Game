# 3in1Game 🎮

A terminal-based mini game hub built using C++.

## Games Included
- Brain Ops
- Rock Paper Scissor
- Toss

## Features
- Randomized gameplay
- Score tracking
- Menu system
- User input handling

## Tech Used
- C++
- STL
